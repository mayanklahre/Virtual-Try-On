# v1.0.0 release notes

**Release notes prepared on 19 October 2026.**

## Shipped
- Modal/CatVTON virtual try-on prototype with persistent model weights.
- ONNX Runtime body parsing, upload validation, HTTP Basic auth, and 5 requests/hour per-IP rate limit.
- Local/deployment guidance and project documentation.

## Known limits
- No measured p50/p95 latency, GPU cost, output-quality benchmark, or automated test suite is claimed.
- Output quality depends on input images and model limits.
- Not a production user-image service; privacy, retention, and stronger access controls require future work.

## Handover
Repository contains setup instructions and quality/measurement checklist.
